# Git Auto-Sync Rule

Whenever code modifications, new features, bug fixes, or assets are completed for this repository:
1. Review `git status` to verify modified/untracked files.
2. Stage appropriate changes (`git add .` or specific files).
3. Commit with a clear, descriptive message (e.g., `git commit -m "..."`).
4. Push to remote (`git push origin main`) to ensure GitHub stays in sync with local work.
